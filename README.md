# Dr-Megha-IrisDent

Dental clinic management application with a holographic iris-style login interface.

## Run locally
1. Extract this ZIP folder.
2. Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Upload `index.html` to the root of the GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Notes
- This is a standalone HTML app; its CSS and JavaScript are embedded in `index.html`.
- Google Fonts and Supabase authentication require internet access.
- Do not store real patient information in an unsecured/public deployment. Confirm database policies, authentication, and backups before clinical use.
- No secret/service-role key should be placed in this repository.
